# CHAON Project

## Overview

CHAON is a youth activity platform designed to increase awareness,
program participation, and facility usage of the Chaoreum youth facility.

## Target Users

Primary:
- Middle school students
- Especially grades 7-8

Secondary:
- Parents
- Youth facility staff

## Purpose

CHAON connects young people with programs, spaces, activities,
events and opportunities available at the youth facility.

The goal is to encourage:

Discover → Participate → Visit → Activity → Record → Return

## Core Functions

1. Programs
2. Program registration
3. Facility information
4. Facility reservation
5. Events
6. Missions
7. Activity records
8. Youth suggestions
9. Volunteer opportunities

## AI Expansion

AI will be introduced as an additional feature.

Potential applications:
- Personalized recommendations
- Program planning
- Promotional content creation
- AI education programs
- Youth idea generation

## Product Direction

The service should feel:
- Easy
- Fun
- Modern
- Youth-friendly
- Useful

It should not feel like a traditional public institution website.
